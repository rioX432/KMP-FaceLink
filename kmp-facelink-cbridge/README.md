# kmp-facelink-cbridge

Shared C bridge for KMP-FaceLink. Provides a stable C API that converts KMP-FaceLink's Kotlin Flow-based streaming into a polling model suitable for non-KMP consumers.

## Consumers

| Consumer | iOS | Android |
|---|---|---|
| Unity | C bridge (`kmpfacelink_bridge_ios.m`) | Kotlin facade (`FaceLinkUnityFacade.kt`) |
| React Native | C bridge (via ObjC++ Turbo Module) | Kotlin facade (`FaceLinkBridgeFacade.kt`) |
| Flutter | C bridge (via dart:ffi) | Kotlin facade (`FaceLinkBridgeFacade.kt`) |

## iOS

The C bridge wraps KMPFaceLink.xcframework's Objective-C API (generated by Kotlin/Native). It creates tracker instances, collects Flow emissions on background threads using `FlowCollectors` helpers, and buffers the latest frame data behind `os_unfair_lock` for thread-safe polling.

The `.m` file is compiled directly into the host Xcode project (static linking). Use `include/kmpfacelink_bridge.h` as the public header.

## Android

The Kotlin facade (`FaceLinkBridgeFacade`) wraps KMP-FaceLink's AAR and provides an identical polling API. Flow collection runs on `Dispatchers.Default` with `AtomicReference` for lock-free thread-safe reads.

## Binary Protocol

| Data | Type | Size |
|---|---|---|
| Blend shapes | `float[52]` | 208 bytes |
| Head transform | `float[6]` | 24 bytes |
| Timestamp | `int64` | 8 bytes |
| Is tracking | `bool` | 1 byte |
| **Face total** | | **241 bytes** |
| Hand landmarks (per hand) | `float[63]` | 252 bytes |
| Handedness | `int32` | 4 bytes |
| Hand count | `int32` | 4 bytes |
| **Hands total (2 hands)** | | **516 bytes** |
